# 四级手术海报 · 视觉模板规范（供批量制作参考）

## 整体规格
- 尺寸：900 × 620（viewBox="0 0 900 620"）
- 文件头：`<?xml version="1.0" encoding="UTF-8"?>`
- 根标签：`<svg xmlns="http://www.w3.org/2000/svg" width="900" height="620" viewBox="0 0 900 620" role="img" aria-labelledby="titleXX descXX">`，含 `<title id="titleXX">` 和 `<desc id="descXX">`

## defs 模板（每张必备）
```xml
<defs>
  <linearGradient id="bgXX" x1="0" y1="0" x2="1" y2="1">
    <stop offset="0" stop-color="#f1f7f8"/>
    <stop offset="1" stop-color="#fff6eb"/>
  </linearGradient>
  <filter id="shXX" x="-10%" y="-10%" width="120%" height="130%">
    <feDropShadow dx="0" dy="5" stdDeviation="7" flood-color="#183642" flood-opacity="0.10"/>
  </filter>
  <style>
    .series { font: 700 14px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; letter-spacing:1.4px; fill:#0072B2; }
    .title { font: 700 31px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#17323d; }
    .kicker { font: 500 17px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#52656c; }
    .nodeTitle { font: 700 18-19px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#17323d; }
    .body { font: 500 15px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#3e5057; }
    .small { font: 500 13px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#5c6c72; }
    .quote { font: 700 19-20px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#17323d; }
    .footer { font: 500 12px 'Microsoft YaHei','Noto Sans CJK SC',sans-serif; fill:#68787e; }
  </style>
</defs>
```
注意：id（bgXX/shXX）每张唯一，用文件名编号。

## 结构骨架
```xml
<rect width="900" height="620" rx="28" fill="url(#bgXX)"/>           <!-- 渐变外底 -->
<rect x="34" y="30" width="832" height="560" rx="24" fill="#ffffff" opacity="0.96" stroke="#dce8e8" filter="url(#shXX)"/>  <!-- 内白卡+阴影 -->
<text x="62" y="68" class="series">四级与整形美容手术 30 讲 · NN</text>  <!-- 系列报头 -->
<text x="62" y="117" class="title">主标题</text>
<text x="62" y="153" class="kicker">副标题（一句话点题）</text>
<line x1="62" y1="181" x2="838" y2="181" stroke="#dce5e5"/>          <!-- 分隔线 -->
<!-- 主体内容（节点卡/对照/流程/时间轴等）放在 y=210~510 区域 -->
<rect x="62" y="525-540" width="776" height="40" rx="12" fill="#eef6f8"/>  <!-- 金句框 -->
<text x="450" y="551-566" class="quote" text-anchor="middle">金句</text>
<text x="62" y="582" class="footer">医学教育示意 · 限制语</text>
```

## 三色语义系统（严格遵守）
| 色值 | 含义 | 用途 |
|---|---|---|
| `#0072B2` / `#56B4E9` | 蓝绿 | 可核验/保护/合规（机构、资质、正面） |
| `#E69F00` | 琥珀 | 待核验/中性/需注意（步骤、提醒） |
| `#D55E00` | 砖红橙 | 急症/高风险/禁忌（四级、并发症、禁止） |
| `#009E73` | 绿 | 二级/中间层级/可选 |
| `#CC79A7` | 紫 | 节点区分/补充 |
| `#17323d` | 深墨 | 标题文字 |
| `#3e5057` / `#52656c` / `#5c6c72` / `#68787e` | 灰阶 | 正文/副标题/小字/页脚 |

## 节点卡模板（主体最常用元素）
```xml
<rect x="X" y="Y" width="250" height="290" rx="16" fill="#f8fbfb" stroke="#0072B2" stroke-width="2"/>
<circle cx="X+43" cy="Y+43" r="22" fill="#0072B2"/>
<text ... class="num" text-anchor="middle">1</text>   <!-- 序号圆 -->
<text ... class="nodeTitle">机构资质</text>
<text ... class="body">条目1</text>
<text ... class="body">条目2</text>
```
- 浅底色随语义：蓝绿用 `#f8fbfb`，琥珀用 `#fff8ee`，红用 `#fdf1ee`
- 卡片底部可加浅色提示框（`#eef6f8`/`#fdf3e3`/`#fbeae3`）

## 内容禁区（必须遵守）
- **不画**针头特写、出血、恐怖对比照、Before/After
- **不画**可供模仿的进针/切口点位
- **不出现**具体金额、具体医生/机构名
- 解剖示意必须加"示意，非教学图"
- 每张底部都要有限制语（footer）

## 命名
- 文件：`<篇号>-<序号>.svg`（如 `06-01.svg`），存 `images-poster/`
- 篇号与文章编号一致（00~29）
- 每篇 2-3 张（重要篇目如颌面/麻醉/栓塞可给 3 张）

## 标点（全系列规范）
- SVG 内中文用全角标点（，。：？！、；）
- 引号用 `&quot;` 转义（在 text 内容里）或避免使用
- 数字+单位半角空格
