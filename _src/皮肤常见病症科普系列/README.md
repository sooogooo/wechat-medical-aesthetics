## 对源文件框架的必要修正

源文件列出26组主题，但多组混合了病因、诊断和治疗完全不同的疾病。为落实“每个病症一篇”，本系列按临床实体拆分，并对同义词、重复项和非规范表述作了以下处理：

1. 痤疮、玫瑰痤疮、荨麻疹和局部多汗症的括号内容属于同一疾病的亚型或部位，合并在各自总论中，避免同一基础知识重复成篇。
2. “激素依赖性皮炎、皮肤屏障受损、重度敏感肌”没有机械拆成三个病名。“屏障受损”是状态，“敏感肌”是症状描述，“激素依赖性皮炎”在公众传播中边界易混，统一为《激素相关性面部皮炎与屏障受损》，重点讲鉴别和用药史。
3. “黄褐斑、炎症后色素沉着、日光性晒斑、颧部褐青色痣”拆为四篇；“日光性晒斑”和后文“日光性黑子”按同一临床实体去重。
4. “脂溢性角化”和“老年疣”是同一疾病的规范名与俗称，合并为一篇；没有把“老年疣”当作HPV疣。
5. 五类色素型胎记太田痣、伊藤痣、咖啡斑、贝克痣及先天性真皮黑素细胞增多症分别成篇，因为自然史、伴随风险和治疗边界不同。标题使用“先天性真皮黑素细胞增多症”，正文说明旧称“蒙古斑”。
6. 慢性湿疹、神经性皮炎、结节性痒疹分别成篇；“肥厚性瘙痒皮损”属于形态描述，不另立病名。
7. 甲真菌病、手足癣、体股癣、花斑癣分别成篇；四类常见非生殖器皮肤疣也分别成篇，以突出部位和自我处理风险。
8. 脱发组拆为雄激素性脱发、斑秃与全秃、瘢痕性脱发、产后休止期脱发。全秃属于斑秃的广泛类型，合并讲解；产后脱发虽只出现在源文件通俗标题中，仍纳入病种映射。
9. 萎缩性痘坑与皮下软组织缺损分篇：前者按瘢痕形态选择治疗，后者强调粘连、容量和分层重建。
10. “色素性痒疹”按规范病名 `prurigo pigmentosa` 撰写，并明确它不是所有抓后色沉的统称。正式发布前建议由临床负责人再次确认原文件是否确指这一少见病。
11. “异物肉芽肿、注射后皮下硬结、填充物残留凸起”作为同一注射并发症鉴别路径合并，不把所有硬结等同为肉芽肿。
12. 胼胝与足部广泛角化合并，鸡眼单独成篇；“瘢痕性色素沉着、炎症后黑变病”与前文炎症后色素沉着高度重叠，映射至同一篇，未制造重复稿件。

## 发布前建议

这些稿件用于公众健康教育，不是对具体患者的远程诊断或处方。正式用于医疗机构账号前，建议由皮肤科临床负责人逐篇署名审校，重点复核中国境内药品、器械和适应证的现行批准状态，以及本机构是否具备眼周激光保护、儿童治疗、急性血管并发症救治、真菌检查、皮肤镜与病理转诊能力。不得把一般医学信息改写成疗效保证、最低价引流、一次根治或“无痕清零”承诺。
