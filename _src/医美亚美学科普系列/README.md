# 医美亚美学 · 10 篇科普系列

重庆西区医院整形外科医疗美容中心 · 医美亚美学科普系列。
延续皮肤、四级手术、美容注射三系列的体例，本系列聚焦**医美行业的审美流派与文化机制**。
特色：盘点 + 反思——既客观介绍各种亚美学，也反思其背后的预设、商业推动与潜在风险。

---

## 这个系列为什么不同

前三个系列（皮肤病症、四级手术、美容注射）主要讲**医学知识**——病种、术式、材料、风险。这个系列讲**审美与文化**——医美行业里那些被命名、被推崇、被争议的"美学流派"。

为什么要做这个系列？因为**医美消费的决策，从来不只是医学决策，更是审美和心理决策。**一个人决定做某个项目，背后几乎总有某种"亚美学"在驱动。如果只讲医学不审视审美，科普反而可能被用来服务于盲目的审美追求。

## 写作立场：盘点 + 反思

- **盘点**：客观介绍每种亚美学的视觉特征、成因、医学实现手段。
- **反思**：点出其背后的审美预设、商业推动、潜在风险（如趋同化、容貌焦虑、不可逆后悔）。

**不反对医美，不否定任何审美选择。**主张的是一种更清醒、更自主的医美消费——看清欲望来源后，做出真正属于自己的选择。

## 体例（每篇统一结构）

沿用前三系列体例，每篇包含：

1. **一级标题**：陈述 + 价值点。
2. **三个备选标题**：供编辑择优。
3. **封面介绍（100 字以内）**：一句话摘要。
4. **正文**：开头"先说结论" + 多个小标题展开。
5. **可视化 SVG 图**：每篇 1–3 张 SVG 图（独立 .svg 文件，images/ 目录引用）（莫兰迪几何风）。
6. **参考资料**：权威来源链接。
7. **反思提示**：文末"本文用于健康教育与文化反思"声明。

## 标点与排版规范（与前三系列一致）

- **GB/T 15834**：中文内容全角标点（，。：？！、；""（）），英文术语/URL 内保留半角。
- **数字 + 单位**：半角空格。

## 合规与发布提示

发布前请由相关负责人复核以下边界：

1. **立场平衡**：本系列"盘点 + 反思"，发布时不应被剪辑成纯批判或纯推销。如果平台需要弱化反思色彩，建议保留"客观介绍"部分，但不应删除"不可逆慎重""警惕营销话术"等安全底线。
2. **不否定个体选择**：全文统一"不构成对任何审美选择的否定"，避免让做过医美的读者感到被评判。
3. **点名限制**：本系列未点名具体明星、网红、机构。发布时不应加入"某某明星的脸就是典型 X 脸"这类指代。
4. **心理内容**：第 10 篇涉及体象障碍和容貌焦虑，发布前建议由临床心理专科复核，确保引导寻求专业帮助的表述准确。
5. **不可逆警示**：多篇涉及"潮流变化与不可逆手术风险"，这是医学安全底线，不应为迎合"想做就做"的语境而弱化。

## 与现有系列的关系

本系列与 `_src/皮肤常见病症科普系列/`（55 篇）、`_src/四级与整形美容手术科普系列/`（30 篇）、`_src/美容注射的艺术科普系列/`（40 篇）形成互补：

- **皮肤系列**：55 个皮肤病症，偏皮肤科诊疗。
- **四级手术系列**：30 个手术主题，偏整形外科决策。
- **注射系列**：40 个注射主题（含 MD Codes），偏微创注射。
- **亚美学系列（本系列）**：10 个审美主题，偏文化与心理反思。

四个系列从"医学知识"到"审美文化"层层递进，共同构成一个相对完整的医美科普体系。可在站内互链：本系列第 02–06 篇可链接到四级手术系列的相关术式篇；第 10 篇可链接到注射系列第 30 篇（何时该停止）。
