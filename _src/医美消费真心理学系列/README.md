## 写作纪律

1. **散文体**，不用列表、不用加粗，段落短，句子短。零冒号零破折号，引号全角配对（对齐 2026-08-18 中台文的标点规则）
2. **用机制代替建议**。少说应该怎样，多说实际发生了什么、为什么会这样
3. **金句少而硬**，每篇两三句足够。不把消费者写成傻瓜，也不把机构写成纯坏人，双方在同一套人性结构里
4. **例子医美原生**。水光、光子、轮廓、抗衰、家用仪器、反复咨询、买而不做。源头的大疆 Pocket 与书单只在第 1 篇作为引子出现
5. **每篇 1000 到 1500 字**（较 Grok 草稿收紧，公众号系列快读体量），独立成文可单读，连续阅读有递进（1-3 讲机制，4-6 讲更深两层，7-8 讲经营者的应对与收尾）
6. **文末标注观点归属**。机制框架归 dontbesilent2025，心理学概念归学界成熟表述，医美映射与行文归本号
