## 设计系统

| 维度 | 规范 |
|---|---|
| 配色 | 暖白 `#FAF8F4` 底 + 墨色 `#2B2A28` 文字 + 莫兰迪鼠尾草绿 `#7A8B6F` / 赭石 `#C9A876` 点缀 |
| 急救色 | 莫兰迪陶土红 `#B5654A`(非刺眼红),与莫兰迪体系和谐 |
| 字体 | 系统字体栈(苹方/思源 fallback),零外部加载 |
| 留白 | 章节间距 ≥ 96px,正文窄栏 700px 居中 |
| 动效 | 卡片 hover 上浮 4px,滚动渐入(IntersectionObserver),200ms Apple ease |

完整令牌见 `assets/css/design-tokens.css`。

## 标点规范(全站执行)

- **GB/T 15834**:中文内容全角标点(`，。：？！、；`),英文术语/URL 内保留半角。
- **数字 + 单位**:半角空格(`24 小时`、`6 周`、`0.5%` 不加空格)。
- **省略号**:`……`(非 `...`)。
- **急救符号**:统一 `⚠` 前缀 + 陶土红配色。

## 上线指引

1. 上传整个 `wechat-pub/` 目录到服务器(替换原 `dermatology-conditions.html` 及相关资源)。
2. 首页路径建议保持 `/dermatology-conditions.html`(可把 `index.html` 重命名或做跳转)。
3. 详情页路径为 `/condition/<slug>.html`,已写入 sitemap 友好的扁平结构。
4. 把首页卡片链接里的 `condition/` 前缀按实际上线路径调整(若详情页放在根目录,需改 `home.js` 的渲染逻辑或做重写)。
5. 转化按钮目前指向 `/contact.html` / 首页,上线前替换为真实的预约/企业微信入口。
6. `_src/` 目录为构建工具,上线时**可删除**(不影响站点运行)。保留它便于后续从源 Markdown 重新生成。

## 后续维护

- **新增/修改病种**:编辑 `assets/data/conditions.json`(首页卡片自动更新);详情页正文改动直接编辑对应 `condition/<slug>.html`。
- **重新生成全部详情页**:修改 `_src/皮肤常见病症科普系列/` 里的 Markdown,在 `_src/` 目录运行 `node build.js`。
- **配色/字号调整**:改 `assets/css/design-tokens.css` 的 CSS 变量,全站即时生效。
