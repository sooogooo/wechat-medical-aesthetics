## 写作定位

**纯科普 + 风险沟通**：解释术式、风险、决策要点，不推销、不点名具体产品/医生/机构、不承诺效果；强调面诊、个体化评估与不确定性。
面向普通消费者（产后人群、大幅减重后人群、考虑体形雕塑者），避免制造外貌焦虑、紧迫感和“奇迹叙事”。

## 体例（每篇统一结构，与全站一致）

每篇 Markdown 包含以下小节：

1. **一级标题**：一句话主标题（陈述 + 价值点）。
2. **三个备选标题**：供编辑择优。
3. **封面介绍（100 字以内）**：一句话摘要。
4. **分级标识**：本系列全部为**四级**（腹壁成形术属四级手术）。
5. **正文**：开头“先说结论” + 多个小标题展开，含风险、决策、面诊要点。
6. **参考资料**：权威来源链接（ASPS、ABCS、中华医学会、国家卫健委等）。
7. **面诊提示**：文末“本文用于健康教育，不能替代面诊”声明。

## 设计原则：按读者决策路径组织

读者不按术式思考，他们按自己的处境思考。因此本系列**不按术式罗列**（mini / standard / extended……），而按读者会问的四个递进问题组织：

1. **我到底是不是这类人？**（先分清问题）
2. **这个手术到底做什么？**（认识手术本身）
3. **代价是什么？**（必须面对的现实）
4. **怎么选、怎么避坑？**（做决定）

每个板块 3 篇，共 12 篇。每篇承担一个明确的决策任务，读者可以从任何一篇进入，也能顺着读完。

## 12 篇目录

### 第一板块：先分清问题（3 篇）—“我到底需不需要”

> 读者在这里判断自己的腹部问题究竟属于哪一类，以及腹壁成形是不是对的工具。

| 编号 | 文件 | 主题 | 切入点 |
|---|---|---|---|
| A1 | `A1-肚子松垮的四种来源.md` | 腹部问题的四来源判断 | 皮下脂肪堆积 / 皮肤松弛 / 腹直肌分离 / 腹壁疝。**核心信息**：先分清来源再谈方案，抽脂解决脂肪，腹壁成形解决皮肤和肌肉。配合诊前自测（捏皮测试、抬肩测试肌分离）。读者产出：一份“我的问题可能属于哪类”的初步判断。 |
| A2 | `A2-产后肚子回不去是腹直肌分离吗.md` | 聚焦产后人群 | 解释 diastasis recti 的形成机制（妊娠期腹白线拉伸）、自测方法、何时需要手术收紧肌层、运动能挽回多少不能挽回多少。**边界**：轻度分离首选康复训练，重度伴功能障碍才考虑手术。 |
| A3 | `A3-大幅减重后的围裙肚.md` | 聚焦减重后人群 | 聚焦大幅减重（含减重术后）的皮肤垂坠、皱褶反复湿疹、活动受限。**核心信息**：这是皮肤过剩问题，不是脂肪问题，抽脂帮不上；环形或倒 T 术式常用于此类人群。讲清减重后需体重稳定 6 个月以上再手术。 |

### 第二板块：认识手术本身（3 篇）—“它到底做什么”

> 读者已大致确认自己属于皮肤/肌肉问题，这里讲清楚手术的机械事实。

| 编号 | 文件 | 主题 | 切入点 |
|---|---|---|---|
| B1 | `B1-腹壁成形的五种术式一张图分清.md` | 术式分型对照 | 迷你型（mini，下腹短切口）/ 标准型（standard，髋至髋）/ 延伸型（extended，绕到侧腰）/ 环形（circumferential / body lift，一周）/ 倒 T 型（fleur-de-lis，横+竖切口）。按切除范围和切口位置对照，说明各自适用人群。**不做“哪个最好”的推荐**，只讲“哪种针对什么”。 |
| B2 | `B2-手术台上到底发生了什么.md` | 术式步骤拆解 | 切口设计 → 掀起皮瓣至上腹 → 收紧分离的腹直肌（折叠缝合 plication）→ 切除多余皮肤 → 重造脐部 → 留置引流。讲清这是四级手术的复杂程度，配合全身麻醉、住院、引流管的现实。让读者理解“为什么这是四级手术”。 |
| B3 | `B3-腹壁成形能和吸脂一起做吗.md` | 联合手术的合理性与边界 | 脂肪型+皮肤松弛的混合人群何时联合、何时分期。**重点风险**：联合吸脂会影响皮瓣血供，增加坏死风险，需主刀评估血供安全边界。讲清“联合”不是“顺便”，而是独立的风险决策。 |

### 第三板块：必须面对的现实（3 篇）—“代价是什么”

> 这一板块是全系列最该“不温柔”的部分：把代价讲透，是对读者最大的尊重。

| 编号 | 文件 | 主题 | 切入点 |
|---|---|---|---|
| C1 | `C1-关于疤痕没有温柔的说法.md` | 疤痕的现实 | 下腹横行疤（十几到几十厘米）+ 脐周疤，可能增生、变宽，穿低腰裤或泳装时可能显露。**核心信息**：对疤痕的接受度是决策的核心之一，宣传“腹壁成形不留疤”的不诚实。讲清疤痕成熟要一年以上、可能需要后续瘢痕管理。 |
| C2 | `C2-那些必须正视的风险.md` | 并发症分级讲解 | 血肿、皮瓣坏死（吸烟/糖尿病高危）、血清肿、感染、深静脉血栓与肺栓塞（严肃并发症）、感觉改变、腹壁不对称、轮廓不平整。按“常见 / 严重 / 需急症处理”分级讲，不制造恐慌也不轻描淡写。**重点**：DVT/肺栓塞的规范预防（早期活动、机械压迫、必要时抗凝）是机构能力的体现。 |
| C3 | `C3-恢复期长什么样.md` | 恢复时间线 | 引流管留置时间、弯腰行走期（hip-flexed gait）、几周能直立、几周能恢复日常、几周能运动、瘢痕成熟的完整周期（约一年）。给一个诚实的恢复时间线，对冲“几天就能上班”的误导。讲清恢复期对生活安排（带娃、工作、运动）的影响。 |

### 第四板块：做决定（3 篇）—“怎么选、怎么避坑”

> 读者已了解术式和代价，这里帮他把决策落实为行动。

| 编号 | 文件 | 主题 | 切入点 |
|---|---|---|---|
| D1 | `D1-这些情况现在别做.md` | 禁忌与“等一等”清单 | 还打算再生育者（再次妊娠会抵消肌层收紧）、体重未稳定者、未戒烟者（皮瓣坏死风险显著升高）、未控制的糖尿病/凝血异常/严重心肺病、对疤痕完全不能接受者。**红线清单**，明确说“现在不是时候”比勉强手术更负责任。 |
| D2 | `D2-面诊腹壁成形的必问清单.md` | 面诊问题清单 | 切口长度和位置、是否联合吸脂、疤痕预期与位置、机构的血库/麻醉能力/血栓预防措施、主刀的四级手术权限与腹壁成形经验。给一份可直接带去面诊的问题清单，附“回答含糊时要警惕”的信号识别。 |
| D3 | `D3-费用构成与为什么差价这么大.md` | 价格逻辑解读 | 四级手术资质成本（硬件、团队、麻醉、住院、引流）决定价格下限；术式复杂度、是否联合吸脂、地区差异决定浮动。**不报具体价格**（地区/时效差异大，且非本系列职责），讲清价格构成的逻辑，帮读者识别“异常低价”可能省掉了什么（血库？麻醉团队？随访？）。 |

## 可视化海报方案（images-poster/）

本系列每篇文章配有 2 张 SVG 可视化海报（共 24 张），存于 `images-poster/` 子目录，命名 `篇号-序号.svg`（如 `A1-01.svg`）。各 md 在“## 正文”后用标准 `![alt](images-poster/xx-yy.svg)` 引用。

**视觉风格（极简版，经用户确认）**：

- 纯白背景＋1px 细边框，无渐变、无投影、无底色填充
- 细线（描边 1～1.2px）、细字重（标题 300、正文 400）
- 颜色只用于描边、序号、重点小字，不用于大面积色块
- 文案禁用全角冒号（生成器自动校验），标题对齐全站“标题去冒号”规范

海报由脚本批量生成，可复现：

```bash
node _src/build-abdominoplasty-posters.js   # 生成 24 张（含结构与冒号校验）
node _src/check-poster-layout.js            # 静态排版核查（文字溢出检测）
```

修改文案或布局时改 `_src/build-abdominoplasty-posters.js` 里对应海报的数据定义后重新运行，不要手改 SVG。`_preview.html` 是浏览器总预览页（需本地起服务，如 `node serve.js` 后访问该文件）。

沿用四级手术系列 `images-poster/` 既有视觉规范：

- 尺寸 900×620，渐变背景（`#f1f7f8`→`#fff6eb`）+ 双层白卡 + 阴影
- 报头结构：“腹壁整形 12 讲 · NN”+ 大标题 + 副标题 + 分隔线
- 三色语义系统：蓝绿 `#0072B2/#56B4E9`=合规/正面、琥珀 `#E69F00`=注意/步骤、砖红 `#D55E00`=高风险/急症
- 底部金句框 +“医学教育示意 · ……”限制语页脚
- 概念化视觉（清单卡/流程图/分层模型/对照卡/时间线），不画针头/出血/恐怖对比/可模仿的切口点位

## 合规与发布提示

发布前请由临床负责人逐篇复核以下边界：

1. **资质表述**：文中“须在有相应资质的医疗机构由具备权限的医师开展”为合规底线，发布时不得弱化为“任何机构都能做”。
2. **效果承诺**：全文不出现“保证满意”“彻底去疤”“平坦如初”“零风险”等承诺；如平台审核要求，可在文末加注“个体效果因人而异”。
3. **点名限制**：本系列未点名具体产品品牌、医生姓名、机构。发布到商业平台时，如需加入本院信息，建议放在文末“了解更多”区，与正文科普内容分隔。
4. **疤痕与风险话术**：C1（疤痕）、C2（风险）是全系列最需诚实之处，发布前确认未出现淡化疤痕、弱化并发症的措辞。
5. **价格话术**：D3 不报具体价格，讲价格构成逻辑；发布前确认未出现具体金额（地区/时效差异大，易过时）。
6. **人群内容**：A2（产后）、A3（减重后）涉及特定人群，确认产后康复、减重术后随访的建议与本院实际接诊能力一致。
7. **急症话术**：C2 涉及 DVT/肺栓塞等需急症的并发症，发布前请与本院急救能力（血库、绿色通道、血管外科协同）对齐，确保文末引导的就医路径与本院实际能力一致。

## 临床审校提示（发布前）

参考皮肤系列与四级手术系列发布经验，发布前建议由整形外科临床负责人逐篇复核：

- 各术式（mini / standard / extended / circumferential / fleur-de-lis）的中文规范命名与属地核准口径。
- 腹直肌分离的分度与手术指征（A2）是否与本院标准一致。
- 联合吸脂的血供安全边界（B3）表述是否准确。
- DVT/肺栓塞的预防措施清单（C2）是否与本院围术期方案一致。
- 恢复时间线（C3）的关键节点（引流拔除、直立、运动）是否与本院术后方案一致。
- 禁忌清单（D1）是否需要增补本院特别强调的项目。
