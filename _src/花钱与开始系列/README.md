# 花钱与开始系列（8 篇）

副题，变美之前，生活早就教过你的八件事。

本系列是《医美消费真心理学》（v1，已存档于 ../医美消费真心理学系列/）的重设计。v1 的问题是用了一批行业和学科词，伪解决方案、获得感、身份表演、决策瘫痪、均衡，读起来像给经营者上的课。本版全部退掉，改成从日常生活里的小事说起，健身卡、收藏夹、买装备、比价、打卡，医美只作为其中一个自然落点。读者不需要懂任何概念，只需要认出自己的生活。

## 写作纪律

1. **零术语**。黑名单，伪解决方案、获得感、身份表演、决策瘫痪、机制、均衡、品项、交付、闭环、干预、依从性、骨相、软组织、心理问题。全部用大白话替换
2. **生活场景开篇**，每篇先讲一件和医美无关的日常小事，医美作为其中一个落点自然出现，不做总结陈词
3. **点拨式收尾**，结尾一两句轻点即止，不升华，不喊口号，不教训人
4. **散文体**，无小节编号，无列表，无加粗。每篇 600 到 1000 字，段落一至三句
5. 标点沿用全系列规矩，零冒号零破折号，引号全角配对
6. 每篇文末一行观察起点归属
