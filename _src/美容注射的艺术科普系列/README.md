# 美容注射的艺术 · 30 篇科普系列

重庆西区医院整形外科医疗美容中心 · 美容注射科普系列。
延续“皮肤常见病症”“四级与整形美容手术”两系列的体例，面向普通消费者，强调风险沟通、资质核实与合理预期。
本系列特色：**每篇 SVG 可视化图（images/ 独立文件）**（与站点莫兰迪配色一致），让科普更直观。

---

## 写作定位

**纯科普 + 风险沟通**：解释注射材料、机制、部位、风险和决策要点，不推销、不点名具体产品品牌/医生/机构、不承诺效果；强调面诊、个体化评估与不确定性。
面向普通消费者（尤其注射受众更广、更年轻），避免制造外貌焦虑、紧迫感和“奇迹叙事”。

## 系列主题：为什么叫“艺术”

把“艺术”理解为：**注射不只是“打针”，而是基于解剖学、材料学和美学判断的精细操作。**注射的有效与安全，建立在理解之上——理解材料、理解解剖、理解自己的诉求和边界、理解何时该停。这种“理解与克制”，正是“艺术”的内核。

## 体例（每篇统一结构）

沿用前两系列体例，每篇包含：

1. **一级标题**：一句话主标题（陈述 + 价值点）。
2. **三个备选标题**：供编辑择优。
3. **封面介绍（100 字以内）**：一句话摘要。
4. **正文**：开头“先说结论” + 多个小标题展开，含机制、风险、决策、面诊要点。
5. **可视化 SVG 图**：每篇 1–3 张 SVG 图（独立 .svg 文件，images/ 目录引用）（本系列特色）。
6. **参考资料**：权威来源链接（FDA、ASPS、AAD、中华医学会、国家卫健委等）。
7. **面诊提示**：文末“本文用于健康教育，不能替代面诊”声明。

## 标点与排版规范（与前两系列一致）

- **GB/T 15834**：中文内容全角标点（，。：？！、；“”（）），英文术语/URL 内保留半角。
- **数字 + 单位**：半角空格（如“24 小时”“6 周”“0.5%”不加空格）。
- **省略号**：……（非 ...）。
- **SVG 内文字**：使用系统字体栈（`-apple-system, PingFang SC, sans-serif`），莫兰迪配色。

## 合规与发布提示

发布前请由临床负责人逐篇复核以下边界：

1. **资质表述**：全文统一"注射属医疗美容操作，须在正规医疗机构由具备资质的医师开展"，不弱化。
2. **产品/品牌**：本系列未点名具体产品品牌、医生、机构（除引用李滨语料的归因格式）。发布到商业平台时，本院信息建议放在文末"了解更多"区。
3. **效果承诺**：全文无"保证满意""零风险""永久"等承诺；如平台要求，可在文末加注"个体效果因人而异"。
4. **法律/监管时效**：所有"以现行版本为准""需另行核验"的标注，发布前请核对：
   - 各注射材料的国内注册状态（透明质酸、再生类、胶原蛋白等产品的注册证会变化）。
   - 肉毒杆菌素产品的国内批准情况。
   - 医疗美容项目分级与机构准入的属地规定。
5. **急救话术**：第 26、27、28 篇涉及栓塞等急症，发布前请与本院急救能力（透明质酸酶备药、血管并发症处理、转诊通道）对齐。
6. **心理内容**：第 30 篇涉及体象障碍，发布前建议由临床心理专科复核。
