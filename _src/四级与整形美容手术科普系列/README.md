## 分级说明

本系列涉及中国医疗美容手术分级管理（一至四级）。理解要点：

- **分级依据风险而非“档次”**：级别反映出血、麻醉、重要结构波及和并发症后果，不等于“更好看”或“更高级”。
- **四级最高**：下颌角、颧骨、正颌、腹壁成形、乳房缩小等典型四级手术，对机构（床位、血库、ICU/绿色通道、麻醉）、医生资质和抢救能力要求最高。
- **本文档的级别标注为科普性质**：具体某项目在某机构的核准级别，以该机构《医疗机构执业许可证》登记和属地卫健部门规定为准。
- **“通常 X 级”的表述**：因术式、麻醉、联合手术不同，同一项目可能跨级，文中已注明“以机构核准为准”。

> 据《联合丽格第一医疗美容医院是如何获得四级手术资质的》（2020-06-12，李滨医美之滨）的观点，四级手术资质形式上批给机构，实质依托具备四级手术能力的团队，且审批需硬件达标（增设病床、血库、ICU、绿色通道）和专家论证。**这是文章中的观点；当前各地审批标准与流程以属地卫健部门现行规定为准，需另行核验。**

## 合规与发布提示

发布前请由临床负责人逐篇复核以下边界：

1. **资质表述**：文中“须在有相应资质的医疗机构由具备权限的医师开展”为合规底线，发布时不得弱化为“任何机构都能做”。
2. **效果承诺**：全文不出现“保证满意”“彻底去疤”“永久不老”“零风险”等承诺；如平台审核要求，可在文末加注“个体效果因人而异”。
3. **点名限制**：本系列未点名具体产品品牌、医生姓名、机构（除引用语料中的历史文章）。发布到商业平台时，如需加入本院信息，建议放在文末“了解更多”区，与正文科普内容分隔。
4. **法律/监管时效**：文中所有“以现行版本为准”“需另行核验”的标注，发布前请核对最新法律法规和属地政策，尤其：
   - 医疗美容项目分级管理目录的更新。
   - 各地四级手术资质审批与备案要求。
   - 药品/植入物的国内批准状态（如透明质酸酶、各类假体）。
5. **急症话术**：第 10、27 篇涉及急救，发布前请与本院急救能力（颌面手术出血、气道、血管栓塞救治）对齐，确保文末引导的就医路径与本院实际能力一致。
6. **儿童与心理内容**：第 26、30 篇涉及儿童病变和心理评估，发布前建议由相应专科（小儿外科/麻醉、临床心理）复核。
