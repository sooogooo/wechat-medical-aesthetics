## 使用方法

1. **按序阅读**：认识（02-05）→ 路径（06-09）→ 实况（10-13）→ 专题（14-15）→ 工具（16）
2. **只读三篇的最小集**：02（行业结构）、08（跨界规律）、16（决策清单）
3. **每篇末尾的三级标注**：事实底座（语料出处）／跨文归纳（作者综合）／需另行核验（诚实欠条）——引用语料观点均标注标题与日期，观点归属原作者
4. **与姊妹系列的关系**：《医美咨询师成长教程》写给零背景入行者（咨询师路径），本系列写给大厂/名校背景者（管理与平台路径）；在"学行业语言、下现场、绝不清单"三个设计点上一致，互相引用不重复展开

## 边界与声明

本系列是职业叙事与决策参考，不构成医疗建议，不构成投资建议；不用于诊断、治疗或项目推荐。语料（李滨医美之滨，2018-2026，本地库 2026-07-10 版）观点归属原作者，其立场属行业"回归医疗"派，系列同时呈现销售导向一派的实况，不替读者选边。涉及当前监管、薪酬、市场数据的内容一律标注"需另行核验"（汇总见第 16 篇附二），发布前按最新权威原文核对。第 13 篇人物为合成原型，正式发布前须以真实采访替换或验证。
