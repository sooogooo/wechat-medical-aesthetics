# 病症插画设计规范（v2 · 具象可识别）

每张 SVG = **清晰可识别的身体部位 + 病症特征叠加**。
不再用纯抽象几何——访问者要一眼看出"这是脸/手/脚/头皮"。

## 核心原则
- **部位先行**:每张图必须先画出可识别的解剖轮廓(脸、手、足、头皮、唇、甲等),再叠加病症。
- **极简线稿**:部位用细线轮廓,不加阴影/渐变/写实细节。
- **病症高亮**:病变特征用色块/虚线/标记突出,与部位轮廓形成层次。
- **统一笔触**:部位轮廓 `stroke-width: 2`,病症细节 `1.2–1.5`,标记线 `0.8`。

## 画布
`viewBox="0 0 120 120"`,部位居中,四周留白 ≥ 14px。

## 配色(沿用站点莫兰迪)
- 部位轮廓:墨色 `#2B2A28`
- 炎症/感染:鼠尾草绿 `#7A8B6F`
- 色素/胎记:赭石 `#C9A876`
- 血管/急救:陶土红 `#B5654A`
- 辅助/结构:暖灰 `#A8A39D`

## 可复用身体部位构件（在 build-svg.js 顶部定义）
- `faceFront()` 正脸轮廓
- `headProfile()` 侧头轮廓(头皮/发际线)
- `scalpTop()` 头顶俯视
- `handBack()` 手背
- `footSole()` 足底
- `lips()` 嘴唇
- `nail()` 指甲
- `arm()` 手臂
- `torsoFront()` 躯干正面(胸背)
- `lowerLeg()` 小腿
