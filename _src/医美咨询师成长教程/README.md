# 医美咨询师成长教程（从小白到上岗）

为一位 28 岁、交通信号专业毕业、零医学背景的转行者定制的十二个月成长课程。全系列以"交通隐喻系统"贯穿：把医美咨询当作一座城市交通来理解，OD 调查对应需求挖掘、信号配时对应面诊节奏、红绿灯对应警讯分级、潮汐车道对应客户经营。

- **设计蓝图**：[00-课程设计总纲](00-课程设计总纲.md)（教学理念、隐喻系统、五阶段地图、通关标准）
- **正文课文**：01-20 课，每课含学习目标、正文（配 SVG 信息图）、作业、通关检验
- **配图**：`images/` 目录，每课一张 800×500 莫兰迪配色信息图，与正文一一对应

## 使用方法

1. **顺序学习**：课程有严格前置依赖（每课头部标注），不建议跳课；总纲第五节的每日节奏（工作日 1 小时 + 周末 3 小时）为准
2. **三件套**：3-2-1 卡片 + 费曼录音 + 错题本，从第 02 课起全程使用
3. **通关制**：每课有通关检验，五个阶段各有一条"绿波带"；结业标准见第 20 课自检清单
4. **教材依赖**：阶段 2 依托本仓库六大科普系列（皮肤 55 篇、注射 40 篇、手术 31 篇、亚美学 10 篇、三型 10 篇、腹壁 15 篇），课文内附精读篇目与路径

## 边界与声明

本教程是职业教育设计，不构成医疗建议；课程立场恒定：咨询师不诊断、不定方案、不承诺疗效、不替医生确认项目、不放大容貌焦虑。语料引用（李滨医美之滨文章）均标注日期与出处，观点归属原作者；涉及法律法规、证书资质、平台规则的内容均标注"需另行核验"，以最新权威原文为准。
