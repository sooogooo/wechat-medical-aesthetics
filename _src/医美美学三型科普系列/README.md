# 医美美学三型 · 10 篇科普系列

重庆西区医院整形外科医疗美容中心 · 医美美学三型科普系列。
延续皮肤、四级手术、美容注射、医美亚美学四系列的体例，本系列聚焦**医美审美的三种境界分类**。
特色：明确褒贬立场——倡导高级型、客观介绍技术型、警示庸俗型，配优雅莫兰迪几何风可视化。

---

## 这个系列的不同

前四个系列分别讲：病种诊疗、外科决策、微创注射、审美文化。这个系列从**审美境界**的角度，把医美思路和结果分为三种型——高级型、技术型、庸俗型，并明确倡导高级型。

立场比《医美亚美学》系列更鲜明：**高级 = 好，庸俗 = 坏**。但批判的是思路、现象与机制（过度、趋同、套模板、追逐流行），**不嘲讽个人**——多数落入庸俗型的人，是在信息不对称中被推动的受害者。

## 写作立场：明确褒贬

- **倡导高级型**：克制、整体、个性化、耐看，是值得追求的方向。
- **客观介绍技术型**：技术是工具，精准本身是好的，但有审美边界。
- **警示庸俗型**：过度、趋同、套模板，无论包装多高端，结果往往显俗。

## 体例（每篇统一结构）

沿用前系列体例，每篇包含：

1. **一级标题**：陈述 + 价值点。
2. **三个备选标题**：供编辑择优。
3. **封面介绍（100 字以内）**：一句话摘要。
4. **正文**：开头"先说结论" + 多个小标题展开。
5. **可视化 SVG 图**：每篇 2–4 张 SVG 图（独立 .svg 文件，images/ 目录引用）（莫兰迪几何风）。
6. **参考资料**：权威来源链接。
7. **审美提示**：文末"本文用于健康教育与审美思辨"声明。

## 标点与排版规范（与前系列一致）

- **GB/T 15834**：中文内容全角标点（，。：？！、；""（）），英文术语/URL 内保留半角。
- **数字 + 单位**：半角空格。
- **省略号**：……（非 ...）。

## 合规与发布提示

发布前请由相关负责人复核以下边界：

1. **立场表述**：本系列明确褒贬，发布时不应被弱化为"都一样好"。但"警示庸俗型"批判的是思路与机制，不应变成对消费者的嘲讽——这一边界已在多篇文章中明确写出。
2. **不否定个人**：全文统一"批判庸俗型现象，不嘲讽个人"，避免让做过相关项目的读者感到被评判。
3. **点名限制**：本系列未点名具体明星、网红、机构。发布时不应加入指代性内容。
4. **技术内容**：第 05–07 篇涉及美学测量、数字化设计，发布前建议由整形外科临床复核术语准确性。
5. **营销合规**：本系列对"套餐""咨询师主导""AI 测脸营销"等持批判态度，发布前请与机构市场/运营确认是否符合调性——本系列实质上反对了部分行业惯例。

## 与现有系列的关系

本系列与 `_src/皮肤常见病症科普系列/`（55 篇）、`_src/四级与整形美容手术科普系列/`（30 篇）、`_src/美容注射的艺术科普系列/`（40 篇）、`_src/医美亚美学科普系列/`（10 篇）形成互补：

- **皮肤系列**：55 个皮肤病症，偏皮肤科诊疗。
- **四级手术系列**：30 个手术主题，偏整形外科决策。
- **注射系列**：40 个注射主题（含 MD Codes），偏微创注射。
- **亚美学系列**：10 个审美流派（幼态脸、高级脸等）。
- **美学三型系列（本系列）**：10 篇审美境界分类（高级、技术、庸俗）。

五个系列构成完整科普体系：从"医学知识"到"审美流派"再到"审美境界"。本系列与亚美学系列最接近，可互链：本系列第 02 篇（高级核心）对应亚美学第 04 篇（妈生款）；本系列第 08 篇（庸俗型）对应亚美学第 05 篇（do 脸感）。
